01

Your first plot, step by step

Offline guide for NumeriPlot 0.1.1 Public Beta. Screenshots were captured from the 0.1.0 source version with the same interface, using only deterministic synthetic data. Version 0.1.1 uses source installation; no prebuilt Mac ZIP is planned.

How to use this guide

Choose a section from the contents or search for a task. Click images to enlarge; press Esc to close. The Türkçe/English link opens the same section in the other language. The guide works offline; external links require internet.

Start with the supplied example
  1. Use File → Open Project… to open examples/NumeriPlot_example_project.json. This is a saved workspace, not a CSV data import.
  2. Inspect the observations and Gaussian curve in Plot. Open Analysis Report to inspect the saved fit parameters and residuals.
  3. Expand Text Management and select the Synthetic data only annotation. Change it with Update or remove it with Delete.
  4. Keep the original example by using File → Save Project As… for your copy. Export the figure separately as PNG, PDF, or SVG.
Create a new plot from CSV
  1. Save your current project first. Use Load Data… for examples/data/noisy_linear.csv and check the x and y columns in the preview.
  2. In Data Table, right-click the x header and assign X; right-click y and assign Y Left.
  3. Choose a plot type, select Add Plot, then open Plot. Add measurement names and units to the axis labels.
  4. Expand Analysis & Fit. Select the series and Linear model, then Fit. Enter starting values and review the report and residuals.
Version and scope

Version 0.1.1 is being prepared for source distribution. Use the Installation link above for setup. Local checks used Apple Silicon, macOS 27.0.1 and Python 3.11.1; other environments are not claimed as validated. This guide describes current 0.1.1 sources; the previous 0.1.0 package lacks recent fixes. Data is processed locally; the running app does not use AI services.

04

Data Import

Choose a CSV, TXT, or Excel file with Load Data or Append Columns. Check the live preview in the import dialog and import only the columns you need.

Import dialog
Separator and encodingFor CSV/TXT, choose automatic detection or comma, semicolon, tab, or space. Encoding choices are UTF-8, Latin-1, CP1252, and UTF-8-SIG. Separator and encoding do not apply to Excel files.
Row structureEnable or disable a header and specify its row. Optionally select a units row; units can be appended to column names while the row is skipped. The extra rows option skips the specified number of rows after the header/units.
Preview and column selectionCompare raw and parsed previews, include or exclude columns, and choose Numeric or Text use for each column. The preview shows up to 200 rows.
Effect on the table

Load Data replaces the current working table and clears its plots, fits, and text. Append Columns adds to the right; rows without matching values are left empty. Check the preview and column types before importing unfamiliar file layouts.

05

Data Table

The table is shared data used by all panels. Header and cell context menus offer different actions depending on the clicked header or selection. The toolbar also has role templates, plot type, reset roles, add plots from roles, and undo last table action.

Column header menu

Right-click a column header to assign a role or rename it. Double-clicking the header cycles through roles.

None, X, Y Left, Y Right, X Error, Y ErrorMarks source-column roles for plotted series. Assigning a role does not transform column contents; how nonnumeric values are handled during plotting depends on plot type.
Role templatesTemplates: Clear all; first column X and remaining columns Y Left; alternating X/Y Left; all Y Left; X followed by Y/Y Error pairs; X, X Error followed by Y/Y Error pairs. Applying a template asks for confirmation. Nonnumeric columns are skipped for Y/error roles.
Plot type and add from rolesPlot types are scatter, line, scatter plus line, bar, and histogram. Add from roles creates drawings in the active panel using assigned X/Y/error roles.
Reset Roles / Undo Last Table ActionReset Roles clears only role assignments. Undo restores the most recent supported table mutation; actions such as loading data or appending columns clear this one-level undo.
Rename ColumnThe name cannot be blank or duplicate another column. Existing series references to that source column follow the new name.
Table body menu

Available commands depend on whether the selection consists of rows, columns, or cells. Deletion and setting cells to NaN require confirmation.

Row selectionDeletes selected rows or inserts blank rows above or below the selection.
Column selectionDeletes selected columns or inserts a blank or index column to their left or right. Deleting every column is blocked.
Cell selection and pasteSets selected cells to NaN, deletes cells and shifts later values upward within each column, or inserts rows. Tab-separated clipboard data can be pasted; values beyond the current column boundary are trimmed and rows are added when needed. Table edits, deletion, paste, and insertion can be undone as the last table action.
06

Panels

A canvas can contain multiple plot panels. The active panel is bold in the list; the series and text lists show items for that panel.

Active panel and layout

Selecting a panel in the list or clicking its plot area makes it active; double-clicking inside a panel selects it and opens Axes settings. Layout choices are 1×1, 1×2, 2×1, 2×2, 3×1, 1×3, 3×2, 2×3, and Custom. Custom layout asks for row and column counts and supports up to 12 panels.

Rename PanelChanges the active panel's display name.
Clear PanelAfter confirmation, removes the active panel's series, fits, and text. It does not delete table data.
Change LayoutSeries and text from panels that no longer fit the new layout are moved to the first panel.
07

Plot Layers and Series

The layer/series list shows drawings in the active panel. Select a row to edit that series; Delete removes the selected series while keeping its source table columns.

Adding and managing series

A column can be used in more than one series. Removing a series does not change the table.

  1. In Data Table, right-click column headers to assign X/Y and optional error roles.
  2. Use the Type list above the table to choose Scatter, Line, Scatter / Line, Bar, or Histogram, then select Add Plot.
  3. Double-click a series name in Layer Management to rename it. Change its appearance through Plot → Styles; Delete removes only the selected drawing.
08

Text and Panel Labels

Individual text items belong to the active panel. Automatic panel labels are one canvas-wide setting and appear on every panel when enabled. Deleting a text item asks for confirmation; turning off automatic labels does not delete individual text items.

Add, edit, and delete text

Math rendering is for mathematical formatting; the input must use valid math syntax.

  1. Enter the text; use the Ω button to choose a symbol if needed.
  2. Choose coordinates: in Axes coordinates, (0,0) is the panel's lower-left and (1,1) its upper-right. In Data coordinates, X/Y are values on the plotted axes.
  3. Set position, horizontal/vertical alignment, size, font, angle, bold, italic, and math rendering. The nine position presets switch the coordinate mode to Axes.
  4. Choose Add for a new item or Update to apply changes to the selected item. Choose Delete and confirm to remove the selected item.
Delete the synthetic-data note example
  1. Open the example project: examples/NumeriPlot_example_project.json.
  2. Expand Text Management in the left panel.
  3. Select 'Synthetic data only · seed 20260831' in the list, choose Delete, and confirm.
  4. Save a copy with File → Save Project As.
Automatic panel labels

The automatic label option displays a panel number/letter label on each panel. Its format, position, alignment, size, bold, and italic settings are configurable; it is off by default.

09

Settings: Axes

Edits X, left Y and, when present, right Y for the active panel named at the top. Right-axis settings alone do not assign a series to the right axis.

Apply and Close

Apply commits the current fields across all tabs and keeps the dialog open. Close does not automatically apply pending fields, but is not an undo button. Color selection, bar Filled and legend reordering can change objects before Apply. When editing multiple series individually, use Apply for each one; selecting another series reloads the style fields.

Frame and ticks
Frame WidthThickness of the frame lines; range 0.5–5.
Bottom / Top / Left / Right FrameShows or hides each side of the main axes frame. With a secondary Y axis, also inspect its frame visually.
Bottom / Top / Left / Right TickEnables tick marks on the selected side. Numeric labels are controlled separately below; enabling top ticks does not add top labels.
Major Tick / Minor TickIn each row the first value is length and the second is thickness. Also increase Minor for the axis to request minor ticks.
Grid
ShowEnables the main axes grid.
: / -- / - / -.Chooses dotted, dashed, solid or dash-dot grid lines.
Opacity0.1 is faint; 1 is fully opaque. Start low so data remains readable.
Controls shared by X, Y (Left) and Y (Right)
AutoUses data-based limits; Min, Max and Step are disabled while checked. Uncheck it to set limits manually. A previously stored positive step can still affect ticks in Auto mode.
Min / MaxEndpoints of the visible range; they do not delete data. Start with Min < Max.
StepNumeric spacing between major ticks on a linear axis. 0 selects automatic spacing. Very small steps can create too many ticks.
Minor0 disables minor ticks; a positive value requests that many minor ticks between major ticks on a linear axis. Do not expect the same subdivision meaning on log axes.
LogSelects logarithmic display. Use positive values and positive manual limits; zero and negative values cannot be displayed on a log axis. The number-format dropdown does not override logarithmic tick formatting.
Show Tick LabelsToggles numeric tick labels; it does not remove tick marks or data.
AngleRotates numeric labels from −90° to 90°. Try 30° or 45° for long X labels.
Number-format choices
AutoChooses ordinary or scientific display and a shared offset when useful.
EScientific notation on each tick, such as 1.000e+03; no separate offset text.
E + OffsetMay show a shared scale/offset separately, leaving shorter tick labels. Include that separate text when interpreting values.
10ⁿUses a×10ⁿ on each tick, without a separate offset.
10ⁿ + OffsetMay use a shared power-of-ten scale and offset. An offset is not forced for every range.
Example: comparable panels
  1. Activate the first panel; uncheck Auto for X and Y in Axes.
  2. Enter Min, Max and a suitable Step; select Apply.
  3. Activate the other panel and apply the same limits; verify matching units too.

Fit appearance

For a selected fit, rendering uses color, line style/width and marker/marker size. Not every visible data-style field is used for fits; Spline does not alter the fit model or calculated curve.

Apply to All (Global Mode)

This mode targets only scatter/line data series in the active panel. It excludes fits, bars, histograms and other panels. The list is disabled; the normal color and individual-marker selectors are hidden. Apply writes the displayed shared style values to all eligible series.

Example: distinguish multiple series

14

Curve fitting and analysis report

A fit adjusts the selected mathematical model to the selected data series. Optimizer convergence is not evidence of scientific validity.

Run a fit
  1. Select the active panel, then a data series in Layer Management. Expand Analysis & Fit.
  2. Choose a formula from the model dropdown. Fit opens the formula and starting parameters; each initial value defaults to 1.0.
  3. Enter estimates suitable for the scale of your data. Blank, text, NaN, or infinite entries are not accepted; correct the field before accepting.
  4. Inspect Plot and Analysis Report. Double-click a fit to rename it; the fit Delete button removes the selected fit curve, not the data series.
Built-in model list

Use the displayed formula as the definition. Gaussian has no baseline term; the model named Exponential Saturation uses A − B·(x+1)^(-k).

Lineary = a·x + b | Simple linear fit with slope (a) and intercept (b)
Gaussian Distributiony = A·exp(-(x-μ)²/2σ²) | Peak height (A), center (μ) and width (σ)
Power Lawy = K·xⁿ | Consistency index (K) and flow index (n)
Exponential Decayy = A·exp(-x/τ) + y₀ | Amplitude (A), time constant (τ) and offset (y₀)
Exponential Saturationy = A - B·(x+1)⁻ᵏ | Saturation limit (A), scale (B) and rate exponent (k)
Single Exponential Saturationy(n) = y₀ + A₁·(1 - exp(-n/λ₁)) | Baseline (y₀), amplitude (A₁), and characteristic cycle (λ₁)
Range, weights, and bounds

Drag horizontally across the plot to select an X range; check the status bar. The range is shared within the running application and does not automatically clear when switching panels. Reselect the full X extent to fit all observations. This version has no separate range-reset button. Fits are unweighted: X/Y error bars are not used by the optimizer. There is no UI for entering lower or upper parameter bounds.

Reading the report
ParametersReported in the order defined by the model. Check the physical meaning of their signs, units, and magnitudes.
N and residualsN is the number of fitted observations. A residual is observed Y minus model Y; inspect the residual plot for structure or trends.
R²1 − SSE/SST. Undefined for constant Y; may be negative. It is not a standalone criterion for model choice or correctness.
RMSE, Mean Error, StdRMSE is the square root of the mean squared residual. Mean Error is the residual mean; Std is the sample standard deviation of residuals (N−1).
Parameter uncertainty warningEven when a curve is drawn, uncertainty estimation may be unreliable. Review data quantity, parameter identifiability, and starting values.
Scientific checks

Check the model domain, selected range, starting estimates, units, and residuals. Compare against synthetic data with known parameters or an independent calculation. Invalid model results and infinite inputs are rejected. The software is not validated for clinical, safety-critical, regulatory, or certification calculations.

Data Operations

Open File → Data Operations, choose a category and operation, select source columns and parameters, inspect Preview, then choose Apply. Operations use row positions; select an X column where required. These are general numerical transformations; choosing an operation does not establish scientific suitability.

Operations and calculation meanings
ScalingNormalize maps the minimum to 0 and maximum to 1 (a constant column becomes zeros). Standardize subtracts the mean and divides by standard deviation (a constant column uses 1 as divisor). Min-Max linearly maps to user-specified bounds; a constant column becomes the lower bound.
Transformlog10 and ln are defined only for positive values and turn other values into NaN. Square root turns negative values into NaN. Absolute value computes |x|; Reciprocal computes 1/x (zero becomes NaN); Power computes x^n and may be invalid for negative inputs with fractional exponents.
Calculus and cumulative operationsAn X column is required for Gradient and cumulative trapezoidal integration. Gradient approximates Y's derivative with respect to that X using np.gradient; integration uses the cumulative trapezoid method and starts at 0. Cumulative sum skips NaN values.
Difference and rolling windowDifference subtracts the value the chosen period earlier; initial rows become NaN. Rolling mean uses at least one valid value per window; rolling standard deviation needs at least two values and is the sample standard deviation.
Two columnsComputes A+B, A−B, A×B, A/B, or 100×A/B. A zero divisor produces NaN. Columns are paired by row position; verify that corresponding rows represent matching observations.
DecimationEvery-n sampling selects every nth value. Window reduction computes the mean, median, minimum, or maximum of consecutive non-overlapping windows; a final short window is included. Output is shorter. It can target the selected column or all numeric columns, either as new columns or in place. In-place changes require confirmation after preview; all-column in-place updates cannot be undone.
Peak findingUses SciPy find_peaks to locate local maxima or, after sign reversal, local minima. Minimum height is a percentage of the selected column's range; minimum distance is in samples. Endpoints are not treated as local peaks. With an X column, peak X and Y values go into two output columns; otherwise one column contains values only at detected peaks and NaN elsewhere.
Preview, output, and limitations

Preview is a sample view of the calculation; it does not validate the model, parameters, units, or scientific inference. Operations change project data; save the project before important transformations.

  1. Choose column A and, where required, column B/X. Values that cannot be converted to numbers become NaN.
  2. Set parameters and choose Preview. Single-column results show the first 10 rows; peak detection shows the first 10 detected peaks.
  3. Choose output column names and select Apply. Names cannot be blank or match existing columns.
  4. For gradient/integration, check units, sampling spacing, and X ordering; for decimation, check row order; for all outputs, inspect NaNs and final-window behavior independently.

Saving projects and exporting

A project file lets you resume editing. Figure, table, and code exports serve separate purposes.

Which output should I choose?
Project JSON · schema 1.0Stores an embedded data copy, series, fits, text, and display settings. Save uses the current destination; Save As chooses another. Use a new name to keep the original.
PNG / PDF / SVGPNG is raster; PDF and SVG are vector formats. Canvas size and DPI affect output appearance. Inspect the exported file in its destination application.
CSV / XLSXExports the current table, without plot styles or project state.
Python / notebookCreates .py / .ipynb files to inspect and reproduce plots in code. Execution needs a suitable Python environment; review the generated code and results.
Important limit: exported fits

Python export may refit all points in the source series when model source is available; do not assume it preserves a restricted UI fit range. The notebook uses the stored fit curve. If you fitted a restricted range, explicitly compare the exported code and curve.

Saving and privacy

A completed save replaces the destination from a temporary file, helping protect old contents on write failure. Still keep independent backups. Project files contain your data; remove private data and personal paths before sharing.

FAQ and safe support

Start with a small synthetic example. Do not include private research or student data in a report.

Quick answers
Where did Synthetic data only come from?It is a saved text item in the example, not a watermark. Text Management → select in list → Delete → confirm.
Why do missing Y rows leave no gaps without X?Automatic X numbers valid Y values 1..n. Supply an explicit X column to preserve measurement gaps.
I changed a setting but the wrong series changed.Check the active panel and selection in Styles. Global Mode targets eligible data series in the active panel, not all panels.
Fit fails / R² is undefined.At least two valid points with distinct X are needed. Check finite values, model domain, range, and initial estimates. R² is undefined for constant Y.
Installation or source-start problemFollow the installation steps in README and SUPPORT. Record the version, OS/architecture, and exact error; remove personal paths before sharing. Ask for support rather than bypassing security warnings or trying arbitrary dependency versions.
What to include in a report

Include version, OS/architecture, ZIP versus source, steps, expected and actual behavior, and a small synthetic example. Use the matching GitHub issue template for ordinary problems; follow SECURITY.md for vulnerabilities or sensitive reports. Logs are not uploaded automatically; sanitize them before sharing.
